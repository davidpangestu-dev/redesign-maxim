# Maxim Redesign — Interactive UX/UI Prototype

Prototype frontend mobile-first untuk presentasi UX/UI redesign Maxim.

## Stack
- React + Vite
- JavaScript
- React Router
- Lucide React
- CSS
- Mock/static data + React state

## Run
```bash
npm install
npm run dev
```

Buka URL Vite yang muncul di terminal.

## Demo flow
- `/welcome` → `/login` → `/otp` → `/profile-setup` → `/`
- `/` → `/bike` → `/bike/confirmation` → `/bike/searching` → `/bike/driver` → `/bike/trip` → `/bike/completed`
- `/` → `/food` → `/food/restaurant` → `/food/cart` → `/food/checkout` → `/food/tracking`
- `/` → `/delivery`

## Notes
- Tidak ada backend/database/API.
- Map adalah mock visual.
- Data dapat reset saat refresh.

## Responsive preview
Desktop uses a centered 390×844 mobile device frame; on narrow screens the prototype becomes full viewport.
